## 👋 About me

I'm **Gonçalo**, a Computer Engineer from **Porto, Portugal** who likes owning the whole stack — from the database and the API to the UI, the Docker containers and the Linux box it all runs on.

- 🎓 **Computer Engineer** (ISPGAYA)
- 🛠️ Background in **Management and Computer Systems Programming** (professional secondary course)
- 🔐 **Cybersecurity certifications** from [Cisco](https://www.netacad.com/) and the Portuguese National Cybersecurity Centre ([CNCS](https://www.cncs.gov.pt/))
- 🎯 Aiming for a **Master's in Artificial Intelligence and Cybersecurity**
- 🚀 **CEO of [JourneyHosting](https://journeyhosting.pt)** — a Portuguese hosting and development company that helps businesses grow their digital presence with reliable infrastructure and close, human support
- 🧩 Owner of [**C# Workbench Studio**](https://github.com/Goncalo17Cardoso/csharp-workbench-studio), a C# extension for VS Code
- 🐧 Owner of the Linux distros **JourneyOS** and **JourneyServer**
- ⚡ Fun fact: I'd rather automate a task twice than do it by hand three times
